# Security Policy

## Never commit
- `.env` files or API keys;
- passwords, tokens, private keys, or executable credentials;
- raw DICOM or other patient-derived imaging data;
- PHI-bearing logs, screenshots, paths, or metadata;
- private institutional paths;
- unreviewed solver or temporary outputs.

## Reporting
After the GitHub repository is created, security issues should be reported through a private GitHub Security Advisory rather than a public issue.

A credential previously present in the private development workspace is not part of this clean repository. Any exposed historical credential must be revoked and replaced before publication.
