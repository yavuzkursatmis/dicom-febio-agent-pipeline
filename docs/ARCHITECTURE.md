# System Architecture

The repository uses deterministic medical-image and mesh tools, Pydantic contracts, LangChain-compatible wrappers, LangGraph downstream orchestration, explicit human-review gates, and safe stopping/limited-reporting states.

The architecture is not described as universally superior to generative-AI agents. Its defensible design advantages are bounded tasks, inspectable intermediate artifacts, deterministic validation, error localization, and human authorization before scientifically consequential transitions.
