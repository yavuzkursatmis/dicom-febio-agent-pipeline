# Reproducibility

Preserved:
- historical checkpoint identifier;
- publication-scope source tree;
- recovered-source SHA-256 hashes;
- portability refactor;
- human-review boundaries;
- solver-validation and claim restrictions.

Not distributed:
- retrospective hospital-archive DICOM;
- patient-derived volumes and geometry;
- solver binary outputs;
- institutional paths and credentials.

Independent replication requires authorized de-identified CT/DICOM data, compatible software versions, local executable paths, human review, and documentation of protocol deviations.
