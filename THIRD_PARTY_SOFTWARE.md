# Third-Party Software

This project interoperates with independently distributed software and Python
packages. Those components are not relicensed by this repository and retain
their respective licenses.

Key external software includes:

- 3D Slicer;
- TotalSegmentator;
- Gmsh;
- FEBio and FEBioStudio;
- Python packages listed in `requirements-core-lock.txt`;
- optional external-AI connectivity listed in
  `requirements-optional-ai-lock.txt`.

No third-party executable, installer, model weight, clinical dataset, or
patient-derived binary artifact is intentionally redistributed here.

A final third-party license review remains required before the
`v1.0.0-publication` release.
