# Data Availability

The validation input is retrospective hospital-archive CT/DICOM data.

Raw DICOM, converted volumes, segmentation masks, patient-derived surface geometry, volume meshes, FEBio model/output binaries, and any artifact with potential re-identification risk are not distributed through this repository.

The public repository contains source code, configuration examples, methodological documentation, sanitized provenance records, and non-identifying technical validation descriptions.

Access to the original dataset is subject to institutional authorization, ethics requirements, privacy controls, and applicable data-protection rules.
